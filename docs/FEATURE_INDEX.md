# SchemaDash Feature Index

| Feature              | Purpose                                                                      | Main Files                                                                                                                                                                                                                                                                                                                               | Notes                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Authentication       | Session bootstrap, password login, OIDC, and route protection                | `frontend/src/context/auth-context/*`, `frontend/src/lib/api/auth-client.ts`, `frontend/src/pages/bootstrap-page/bootstrap-page.tsx`, `frontend/src/pages/sign-in-page/sign-in-page.tsx`, `backend/src/routes/auth-routes.ts`, `backend/src/services/auth-service.ts`, `backend/src/security/request-access.ts`                          | Controls access to admin and schema-sync operations.                                                           |
| Dashboard / Library  | Browse all diagrams, collections, shared items, profile, settings, and trash | `frontend/src/pages/dashboard-page/*`, `frontend/src/dialogs/open-diagram-dialog/open-diagram-dialog.tsx`, `backend/src/routes/persistence-routes.ts`                                                                                                                                                                                    | Frontend shell backed by persistence APIs.                                                                     |
| Diagram Editor       | Main canvas editing experience and provider stack                            | `frontend/src/pages/editor-page/*`, `frontend/src/context/schemadash-context/schemadash-provider.tsx`, `frontend/src/context/canvas-context/*`                                                                                                                                                                                           | Core frontend runtime for diagram editing.                                                                     |
| Persistence          | Save/open/update/delete collections, projects, diagrams, and config          | `frontend/src/context/storage-context/storage-provider.tsx`, `frontend/src/lib/api/persistence-client.ts`, `frontend/src/lib/persistence/*`, `backend/src/services/persistence-service.ts`, `backend/src/repositories/app-repository.ts`                                                                                                 | Local Dexie cache plus backend durable storage.                                                                |
| Sharing              | Project/diagram sharing settings, share tokens, and shared viewers           | `frontend/src/dialogs/open-diagram-dialog/use-sharing-settings-dialog-api.ts`, `frontend/src/dialogs/open-diagram-dialog/sharing-settings-dialog.tsx`, `frontend/src/pages/shared-project-page/*`, `frontend/src/lib/persistence/share-token.ts`, `backend/src/utils/request-share-token.ts`, `backend/src/routes/persistence-routes.ts` | Sharing is integrated through native dialog, lib, and storage-context boundaries instead of a feature subtree. |
| Collaboration        | Diagram sessions, presence, heartbeats, and SSE updates                      | `frontend/src/context/storage-context/storage-provider.tsx`, `frontend/src/context/schemadash-context/schemadash-provider.tsx`, `backend/src/services/diagram-collaboration-broker.ts`, `backend/src/services/diagram-presence.ts`                                                                                                       | Snapshot-based live sync, not CRDT/OT.                                                                         |
| Schema Sync          | PostgreSQL connections, import, diff preview, SQL apply, audits              | `frontend/src/dialogs/schema-sync-dialog/schema-sync-dialog.tsx`, `frontend/src/lib/api/schema-sync-client.ts`, `frontend/src/lib/schema-sync/*`, `backend/src/routes/schema-sync-routes.ts`, `backend/src/services/schema-sync-service.ts`, `backend/src/services/apply-service.ts`, `packages/schema-sync-core/src/*`                  | Strongest frontend/backend/shared-package integration point.                                                   |
| Import / Export      | SQL, DBML, metadata, image, diagram, and backup flows                        | `frontend/src/dialogs/import-database-dialog/import-database-dialog.tsx`, `frontend/src/dialogs/export-sql-dialog/export-sql-dialog.tsx`, `frontend/src/lib/data/*`, `frontend/src/lib/dbml/*`, `backend/src/schemas/project-backup.ts`                                                                                                  | Mostly frontend logic with backend backup endpoints.                                                           |
| Templates / Examples | Browsing and cloning starter diagrams                                        | `frontend/src/pages/templates-page/*`, `frontend/src/pages/template-page/*`, `frontend/src/pages/examples-page/*`, `frontend/src/templates-data/*`                                                                                                                                                                                       | Frontend-only and relatively isolated.                                                                         |
| Admin / Operations   | Admin overview, runtime health, deployment surfaces                          | `frontend/src/pages/admin-page/admin-page.tsx`, `frontend/src/pages/admin-page/admin-route-guard.tsx`, `frontend/src/lib/api/admin-client.ts`, `backend/src/routes/admin-routes.ts`, `backend/src/routes/health-routes.ts`, `docker-compose.yml`                                                                                         | Depends on auth and persistence state being healthy.                                                           |
| Shared UI Layer      | Reusable primitives for dialogs, cards, forms, tables, navigation, feedback  | `frontend/src/components/*`                                                                                                                                                                                                                                                                                                              | Cross-cutting dependency for nearly every frontend feature.                                                    |
